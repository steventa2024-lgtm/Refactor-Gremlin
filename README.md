## ⚡ Overview

**Refactor Gremlin** is a lightweight Windows desktop companion engineered by **ZeroPulse Automation**. It hovers above your IDE and workspace, air-gapped on your local GPU VRAM.

Highlight untyped payloads, messy tailwind strings, or nested callbacks, tap **`Alt + R`**, and watch the gremlin morph into an overclocked CRT workstation that writes instant drop-in code directly back to your clipboard.

- **Zero Cloud Latency:** Runs entirely on `localhost:11434` with sub-400ms turnaround on modern RTX hardware.
- **Zero Monthly Subscriptions:** 100% free and open local architecture powered by Qwen 2.5 Coder 7B.
- **Auto-Hydrating Architecture:** One-click installer (~90 MB) that automatically manages its background local daemon without requiring manual terminal configuration.

## 🎮 Desktop Controls & Shortcuts

| Action | Control | Description |
| :--- | :--- | :--- |
| **Refactor Clipboard** | `Alt + R` | Ingests highlighted code, morphs into CRT terminal, and replaces clipboard. |
| **Pin & Lock** | **Double-Click** | Locks gremlin in place with Cyber Gold theme (`★ . ★`). Prevents dragging. |
| **Unpin & Unlock** | **Triple-Click** | Unlocks gremlin with Phantom Purple theme (`~ . ~`). Allows fluid dragging. |
| **Compiler Menu** | **Right-Click** | Opens context menu to switch compiler modes or preview hydration sequence. |

---

## 🛠️ Compiler Modes

- **Strict TypeScript (`TS`):** Infers strict interfaces and types from raw JSON or untyped JavaScript objects.
- **Tailwind CSS (`TW`):** Deduplicates, strips conflicting utility classes, and sorts layout classes.
- **Clean Logic (`LOGIC`):** Refactors nested callback pyramids into early-return guard clauses and modern ES6+.
